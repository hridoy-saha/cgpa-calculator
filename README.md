# Bangladesh UGC CGPA Calculator

Simple browser-based calculator implementing the common Bangladesh UGC grading scale.

Usage
- Open `index.html` in your browser.
- Click **Add Course** to add rows. Enter the semester, credits, and marks (%) for each course.
- Click **Calculate CGPA** to compute the weighted CGPA using the UGC grade mapping.
- Use **Show** to view semester-wise GPA, course-wise grades and points, or both together.

UGC grading scale used (marks → grade → grade point)

- 80-100: A+ → 4.00
- 75-79: A → 3.75
- 70-74: A- → 3.50
- 65-69: B+ → 3.25
- 60-64: B → 3.00
- 55-59: B- → 2.75
- 50-54: C+ → 2.50
- 45-49: C → 2.25
- 40-44: D → 2.00
- 0-39: F → 0.00
